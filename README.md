# mubo-agent-team

## 辞書的定義

GitHubを共有作業空間に、人間と複数のローカルAIエージェントを協働させるアプリケーション構想を管理するリポジトリです。[コンセプト文書](docs/application-concept.md) ではアプリ名を Mobo、ローカル環境のブートストラップ基盤を mubo と表記しています。現在は構想資料のみで、実行可能なアプリは収録していません。

## 用語としての用例

「外出先で整理した依頼を、自宅の計算機へ委譲し、GitHubのPRでレビューする」が想定例です。Mobility エージェントが対話・意図整理、Compute エージェントが重い生成・実装を担い、人間が最終判断する非同期リレーを指します。

## 思想的背景

文脈がチャットや端末ごとに分断される問題に対し、役割、意思決定、成果、ふりかえりを継続できるチームとして扱う構想です。人間レビューを省く完全自律化ではなく、説明可能性と継続性を重視しています。

## 技術的背景

コンセプトでは、mubo、Ollama、GitHubのIssue / PR / ログを組み合わせ、端末間接続の候補にTailscaleを挙げています。これは採用・実装済み構成の宣言ではありません。2台の役割分担と承認経路を設計する資料として読んでください。

## 歴史的背景

[2026年3月12日のコミット](https://github.com/masa-san-jp/mubo-agent-team/commit/e170efac90d26c27d13fe10e271a955d39499fed) で Mobo のコンセプト文書を追加しました。リポジトリ内で確認できる履歴はこの構想の文書化で、サービス提供や運用実績を示すものではありません。

## 展開

詳細な利用像、安全性、非目標、成功条件は [application-concept.md](docs/application-concept.md) を参照してください。実装に進む場合は、構想上の要素を具体的な要件・接続方式・検証条件へ落とす段階が必要です。現時点ではインストール・起動手順はありません。
